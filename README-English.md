# C Programming Notes

[中文](README.md)

This repository contains a progressive set of C programming notes. It starts with programming fundamentals and development tools, then moves through core C syntax, data types, pointers, dynamic memory, and file operations.

The current materials are provided as two Word documents. They are intended for systematic study, classroom review, and hands-on C programming practice.

## Learning Path

The recommended reading order is:

1. Learn what programs and programming languages are, and review the background of C.
2. Set up a C development environment and build the first C program.
3. Study variables, constants, number bases, data types, and type conversions.
4. Master operators, expressions, and control-flow statements.
5. Learn arrays, strings, functions, and scopes.
6. Understand pointers, the relationship between pointers and arrays, and function pointers.
7. Study the preprocessor, user-defined types, and structured data.
8. Learn dynamic memory allocation and basic file operations.
9. Reinforce the material with breakpoint debugging and exercises.

## Contents

### C Programming Notes 01

The first document covers the C language fundamentals:

- **C Language Overview**: The concept of a program, the history of programming languages, and the development and versions of C.
- **Getting Started with C Development**: Choosing development tools, installing MinGW-w64, and installing and configuring VS Code.
- **The First C Program**: Creating, compiling, running, and analyzing a `Hello World` program.
- **How a C Program Runs**: Preprocessing, compilation, assembly, linking, and execution.
- **Variables and Constants**: Variable declarations, input and output, identifiers, keywords, `#define`, and `const`.
- **Binary and Number-System Conversions**: Binary, decimal, and hexadecimal numbers, plus sign-magnitude, one's complement, and two's complement.
- **Data Types**: Integers, floating-point values, characters, Boolean values, format specifiers, and type conversions.
- **Operators**: Arithmetic, relational, logical, assignment, bitwise, and conditional operators, along with operator precedence.
- **Control-Flow Statements**: Sequential execution, branches, `switch`, `while`, `do...while`, `for`, nested loops, and jump statements.
- **Breakpoint Debugging**: Setting breakpoints, stepping through code, and debugging with breakpoints.

### C Programming Notes 02

The second document builds on the fundamentals and introduces more core C topics:

- **Arrays and Strings**: One-dimensional arrays, character arrays, multidimensional arrays, traversal, and out-of-bounds access.
- **Functions**: Function declarations, calls, parameters, return values, prototypes, and scope.
- **Recursion and Common Functions**: Recursive functions and common string, input/output, date/time, and math functions.
- **Pointers**: Addresses, dereferencing, pointer arithmetic, pointers and arrays, character pointers, function pointers, and multi-level pointers.
- **Pointer Safety**: Null pointers, wild pointers, out-of-bounds access, and use-after-free issues.
- **The Preprocessor**: Macros, function-like macros, file inclusion, and conditional compilation.
- **User-Defined Types**: Enumerations, structures, unions, and `typedef`.
- **Dynamic Memory Allocation**: `void *`, `malloc`, `calloc`, `realloc`, `free`, and basic memory-management principles.
- **File Operations**: Standard input and output, opening and closing files, file reading and writing, and common file functions.

## Development Environment

The notes use Windows-based C development examples. The recommended tools are:

- [Visual Studio Code](https://code.visualstudio.com/): Edit C source code.
- [MinGW-w64](https://www.mingw-w64.org/): Provides a GCC-based compiler toolchain.
- The **C/C++ Extension Pack** for VS Code: Supports C/C++ editing, compilation, and debugging.

You may also use Visual Studio, Code::Blocks, CLion, or an online C compiler according to your preferences.

## Reading Suggestions

- Read the concepts first, then run the code examples from the documents.
- Create a separate practice directory for each chapter and record compiler output and debugging steps.
- Pay particular attention to the relationships among pointers, arrays, functions, and dynamic memory.
- When a topic depends on a compiler, operating system, or platform, verify it in your current development environment.
